# WikiDoc - Android Wiki管理应用设计方案

## 一、应用概述

**应用名称**: WikiDoc  
**定位**: 一款功能完善的本地Wiki文档管理应用，支持完整Markdown语法、高效预览、批量导入导出。

### 核心特性
- 完整Markdown语法支持（GFM扩展语法）
- 实时/分屏预览模式
- 文件夹分类管理
- 全文搜索
- 图片管理与上传
- 批量导入导出（支持SMB协议）
- 纯本地存储，保护隐私

## 二、整体架构设计

### 2.1 架构模式
采用 **MVVM + Clean Architecture** 模式：

```
┌─────────────────────────────────────────────────────────────┐
│                    Presentation Layer                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │   Compose   │  │  ViewModel  │  │      UiState        │  │
│  │     UI      │◄─┤   (Hilt)    │◄─┤  (Sealed Classes)   │  │
│  └─────────────┘  └──────┬──────┘  └─────────────────────┘  │
└──────────────────────────┼──────────────────────────────────┘
                           │
┌──────────────────────────┼──────────────────────────────────┐
│                    Domain Layer                              │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │   UseCase   │  │   Entity    │  │   Repository        │  │
│  │  (Interact) │◄─┤  (Model)    │◄─┤   Interface         │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────┼──────────────────────────────────┐
│                    Data Layer                                │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │   Room DB   │  │ File System │  │    SMB Client       │  │
│  │  (Local)    │  │  (Storage)  │  │   (jcifs)           │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 模块划分

| 模块 | 职责 |
|------|------|
| `app` | 应用入口，依赖注入配置，导航 |
| `presentation` | UI层，Compose界面，ViewModel |
| `domain` | 业务逻辑，UseCase，实体类 |
| `data` | 数据层，Repository实现，数据库，文件操作 |
| `core` | 公共工具类，扩展函数，常量 |

### 7.1 支持的语法

| 语法 | 说明 | 示例 |
|------|------|------|
| 标题 | H1-H6 | `# 标题` |
| 段落 | 普通文本 | 普通段落 |
| 加粗 | **粗体** | `**粗体**` |
| 斜体 | *斜体* | `*斜体*` |
| 删除线 | ~~删除~~ | `~~删除~~` |
| 行内代码 | `code` | `` `code` `` |
| 代码块 | 语法高亮 | ` ```kotlin ` |
| 引用 | 引用块 | `> 引用` |
| 有序列表 | 数字列表 | `1. 项目` |
| 无序列表 | 符号列表 | `- 项目` |
| 任务列表 | 待办事项 | `- [ ] 任务` |
| 链接 | 超链接 | `[文本](url)` |
| 图片 | 图片插入 | `![alt](path)` |
| 表格 | GFM表格 | `| 列 |` |
| 分割线 | 水平线 | `---` |
| 脚注 | 注释说明 | `[^1]` |
| 数学公式 | LaTeX | `$E=mc^2$` |
| 流程图 | Mermaid | ` ```mermaid ` |
| 目录 | TOC | `[TOC]` |

### 7.2 编辑器工具栏

```
┌─────────────────────────────────────────────────────────────┐
│  B  I  U  S  H1  H2  H3  •  1.  []  <>  🖼  📊  ⋮         │
└─────────────────────────────────────────────────────────────┘
```

| 按钮 | 功能 | 快捷操作 |
|------|------|----------|
| B | 加粗 | `**选中文本**` |
| I | 斜体 | `*选中文本*` |
| U | 下划线 | HTML `<u>` |
| S | 删除线 | `~~选中文本~~` |
| H1-H3 | 标题 | `# / ## / ###` |
| • | 无序列表 | `- 项目` |
| 1. | 有序列表 | `1. 项目` |
| [] | 任务列表 | `- [ ] 任务` |
| <> | 代码块 | ` ``` ` |
| 🖼 | 插入图片 | 打开图片选择器 |
| 📊 | 插入表格 | 表格模板 |
| ⋮ | 更多选项 | 脚注、公式等 |

## 八、性能优化策略

### 8.1 预览优化
- **延迟渲染**: 大文档分块渲染
- **缓存机制**: 预览结果缓存
- **WebView复用**: 预加载WebView实例
- **异步解析**: 协程异步解析Markdown

### 8.2 搜索优化
- **FTS5全文索引**: SQLite全文搜索
- **索引增量更新**: 仅更新变更文档
- **搜索结果缓存**: 缓存常用搜索结果

### 8.3 列表优化
- **分页加载**: Paging 3库
- **懒加载**: LazyColumn
- **占位图**: 加载中状态

### 8.4 图片优化
- **压缩存储**: 自动压缩大图
- **缩略图**: 列表使用缩略图
- **内存缓存**: LRU缓存策略
